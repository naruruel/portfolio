# ===== 更新ログの書き方 =====
# このファイルに書いた内容が、サイトの「更新ログ」に表示されます。
#
# ・1件ごとに「---」だけの行で区切ります。
# ・1行目は「日付 | タイトル」と書きます（日付は 2026-07-24 のような形）。
# ・2行目からが本文です。途中に空行を入れても大丈夫です。
# ・最後の行が http で始まっていれば「詳しく見る →」のリンクになります。
# ・並べる順番は気にしなくて大丈夫です。新しい日付が自動で上に来ます。
#   （同じ日付どうしは、このファイルに書いた順に並びます）
# ・「#」で始まる行は表示されません（この説明のような覚え書きに使えます）。
#   本文の行頭に # を書くと、その行は表示されないのでご注意ください。
#
# 記入例：
# ---
# 2026-10-01 | 新しい作品を公開しました
# 本文をここに書きます。
# https://x.com/naruruel
#
# ===== 投稿をそのまま載せる書き方 =====
# ・区切り（---）の中に、X か Bluesky の投稿URLを1行だけ書くと、
#   その投稿が公式の埋め込み表示（明るい配色・日本語）で載ります。
#     X       … https://x.com/名前/status/数字
#     Bluesky … https://bsky.app/profile/名前/post/英数字
# ・日付やタイトルは書かなくて大丈夫です。
#   投稿URLから投稿日（日本時間）を自動で割り出し、ほかの記事と一緒に新しい順に並べます。
# ・URLの後ろに /photo/1 や ?s=20 などが付いていても、そのままで大丈夫です。
# ・URLのほかに1文字でも書くと、上の「日付 | タイトル」の記事として扱われます。
# ・投稿が削除されている、見る人の環境で X や Bluesky が開けない、などで
#   埋め込みが出せないときは「Xの投稿を見る →」のようなリンクだけが表示されます。
# ・どちらの書き方も、このファイルの中で自由に混ぜて使えます。
#
# 記入例：
# ---
# https://x.com/naruruel/status/2105946191494316260
# ---
# https://bsky.app/profile/example.bsky.social/post/3lxxxxxxxxxxx
